Vaultic

Privacy Policy

Last updated: November 13, 2026

1. Who we are and scope

Vaultic is a personal, self-hosted net worth dashboard run by one individual (the "owner") for the owner's household. It is not a commercial service. There is no public sign-up: user accounts are created only by the owner, and the app has two household users. This policy describes what data the app collects, why, who receives it, and how it is protected and removed.

2. Data we collect

  • Financial data from Plaid (only for institutions a user chooses to connect): institution name, account names and types, balances, investment holdings and securities, investment transactions, and bank transactions.
  • Financial data from other sources: holdings, balances, performance and activity from the household's investment and retirement account providers (imported by the owner's own scripts or by uploading statements), Coinbase balances via its API, and values users enter manually (for example home, vehicle or credit score values).
  • Uploaded PDF statements. Text is extracted on the server. Statements in a format the app parses natively are processed entirely on the server. For other formats, the extracted text (not the PDF file itself, and capped at the first 30,000 characters) is sent to Anthropic's Claude API to be converted into structured data (see section 4).
  • Account and security data: username, a bcrypt hash of the password (never the password itself), an encrypted two-factor (TOTP) secret, session and refresh tokens, and a security log containing login attempts (time, IP address, user agent), authentication failures and request metadata.
  • Browser push subscription details, if a user turns on notifications.

We do not collect data from visitors to this documentation site and use no cookies, analytics or advertising trackers.

3. How Plaid is used

Vaultic uses Plaid to connect financial accounts, only with the user's consent through Plaid Link. Bank login credentials are entered into Plaid's interface and are never seen or stored by Vaultic; the app stores only an access token, which is encrypted at rest. A user can disconnect an institution at any time; doing so calls Plaid's item-removal endpoint, deletes the stored access token and deactivates the linked accounts. Plaid's handling of data is described in the Plaid End User Privacy Policy.

Data may also be disclosed if required by law.

5. Storage and security

Traffic is encrypted in transit with HTTPS. Plaid access tokens and two-factor secrets are encrypted at rest with Fernet (AES-based) encryption, and passwords are stored as bcrypt hashes. Access requires a password plus two-factor authentication, and is limited to the household's users and the owner as administrator. Other application data, such as balances and transactions, is stored in the application database without separate application-level encryption and relies on access controls and the hosting and backup providers' storage protections. See the Information Security Policy for details.

6. Retention and deletion

  • Net worth history and account data are kept for as long as the account is in use, because history is the purpose of the product.
  • Database backups are kept for 7 days in cloud storage and 72 hours on the local backup replica.
  • Security logs rotate automatically and server logs are kept for 7 days.
  • Disconnecting an institution removes the Plaid item and its access token.
  • On request, the owner deletes a user's data manually. Deleted data may remain in backups until they expire as described above.

7. No sale, no advertising

We do not sell personal or financial data, we do not use it for advertising, and the app contains no third-party analytics or tracking scripts (the news thumbnail requests above are the only content the browser fetches from other sites).

8. Your rights and how to contact us

Users may ask to see, correct or delete their data, or to disconnect any connected institution. Contact the owner through the owner's GitHub profile. Please do not post account or financial details in a public issue.

9. Changes to this policy

We will update this page and its "last updated" date when the app's data practices change.
